## Featured

### [ecommerce-rest-api](https://github.com/thesunnycode/ecommerce-rest-api)

A production-oriented e-commerce backend — **24 REST endpoints across 6 modules** on a normalized
**10-table MySQL schema**.

- Stateless **JWT** auth with access + refresh tokens; refresh token in an `HttpOnly`, `Secure`,
  path-scoped cookie; **BCrypt** password hashing
- Role-based authorization with deny-by-default rules, composed per feature module
- **Stripe Checkout** behind a `PaymentGateway` abstraction, with payment confirmed
  asynchronously via **webhook signature verification**
- Order items snapshot the unit price at purchase time, so historical orders stay immutable
- **Flyway** migrations · **MapStruct** compile-time DTO mapping · **OpenAPI** docs ·
  `@EntityGraph` fetch plans to avoid N+1

`Java 17` `Spring Boot 3` `Spring Security` `JPA/Hibernate` `MySQL` `Stripe`
